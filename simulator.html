Newsletter simulator

Pick an edition and see exactly which events an editorial system would ingest for it, which of them still have no real title, and what the listing looks like made up.

Runs entirely in your browser against the published feeds. Nothing is sent anywhere and nothing is changed. The feeds and their labels are discovered from status.json, so a source added to the registry appears here without this page being edited.

Edition

 

Advanced

The deadline is derived from the publication date — the Tuesday of the week before, at noon — and the window runs from the publication date to that week's Sunday. Override any of these to model an exception. An edition that shifts for a holiday is an exception: the week of 7 September 2026 publishes on the Tuesday, so set the publication date to the 8th to reproduce it. Choosing a new publication date derives the deadline again.

Sources

Each feed reproduces one unit's calendar faithfully and none of them de-duplicate, so selecting two units that both list the same talk shows it twice — which is what an editor actually has to resolve. Anything that looks like a repeat is counted below.
